# BuyNest - Frontend (Backoffice)

```bash
npm install
npm run dev          # http://localhost:5173 (proxy de /api e /hubs para o Gateway em :5000)
npm test          s   # Vitest
npm run e2e          # Playwright (com o backend no ar)
npm run i18n:check
```

Veja o [README principal](../README.md) para arquitetura, configuração e como rodar o sistema completo.
